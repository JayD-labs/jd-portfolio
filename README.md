# JD Portfolio

Meine persönliche Portfolio-Website und ein praktisches Lernprojekt für meinen Einstieg in die IT.

Ich entwickle die Website selbst und nutze sie, um meine Kenntnisse in Webentwicklung, Git/GitHub, Responsive Design und Accessibility praktisch auszubauen.

🌐 **Live:** [jd-schuldt.de](https://jd-schuldt.de)

## Aktueller Stand

- semantisches HTML
- eigenes CSS-Design mit Design-Tokens
- Responsive Layout
- Hero-Bereich mit Profilbild
- interaktive Skill-Karten mit JavaScript
- grundlegende Accessibility
- GitHub Pages Deployment
- eigene Domain

## Technologien

- JavaScript
- Git
- GitHub
- GitHub Pages
