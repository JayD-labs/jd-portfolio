## Entwicklungsworkflow

Größere Änderungen entwickle ich in eigenen Feature-Branches und integriere sie anschließend in `main`.

Kleinere, überschaubare Änderungen und Korrekturen können direkt auf `main` erfolgen.

Der grundlegende Ablauf bei größeren Änderungen ist:

```text
Feature-Branch erstellen
→ Änderung entwickeln
→ lokal testen
→ committen
→ in main mergen
→ main pushen
→ abgeschlossenen Feature-Branch löschen
```
